## Возможности

- Авторизация по логину/паролю (SHA-256 + salt, SQLite)
- Админ: учётки, онлайн, результаты, оценки, АИС 112, параметры
- Преподаватель: задания только ученикам **в сети**, результаты, оценки
- Presence (heartbeat 15 с, TTL 45 с)
- Тренажёр: вызовы, карточка вручную, оценка в %

## Запуск в LAN

```bash
python3 server.py
```
